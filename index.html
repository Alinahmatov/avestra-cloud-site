    What it sees

    A room, a database, a journal.

    Local AI on Windows. Point this PC’s camera, CCTV, PTZ, Wi‑Fi, GoPro, or a phone at the node, switch among them, and the stream is analysed here: faces you enrolled, COCO objects, a journal of who walked through. It will not sign in without a license from the Developer.

    Face recognition

    Enroll faces on this PC. Known people show as Person N · Name. Everyone else stays Person N until you put them in the database. You don’t type labels on every frame.

    COCO object detection

    Chair. Laptop. Phone. Bed. Bottle. Everyday objects get names from COCO so the room is readable — and triggers can fire on what is actually there. Not a shopping catalog.

    Action journal

    Who entered. Who left. Wave, sit, stand, possible fall. Lines use Person N · Name, with clothing in the description when the torso read is good. Searchable, not a vibe.

    People database

    Its own local store on this PC. Enrolled faces, unnamed Person N tracks, history. The database lives next to the app, not in a vendor account you don’t control.

    Occupancy

    How many people are in frame right now while monitoring. Peak and unique counts for the day. Watch a shop or a room without guessing from a silent thumbnail.

    How it works

    Install it. Point it. Read who walked through.

    USB, CCTV, PTZ, Wi‑Fi, GoPro, or phone. Faces, COCO objects, occupancy, and a weekly report — on this PC.

    1. 1

      Download Setup.exe

      Get AvistraCloud-Setup.exe from this page (GitHub Releases). Run it. Installing does not create an account and does not include Avistra Access.

    2. 2

      Sign in with four things

      Access URL + nickname + password + license from the Developer. You cannot invent any of them. Expired licenses are refused.

    3. 3

      Pick the cameras, enroll people

      Settings → add and switch sources: this PC’s USB camera, CCTV / PTZ / Wi‑Fi over RTSP, GoPro (USB, Wi‑Fi, or RTMP onto this PC), or a phone camera over Wi‑Fi. People → add faces you want named. Anyone else stays Person N — still tracked, still journaled.

    4. 4

      Start monitoring

      Live → Start. Boxes, occupancy, action journal — scanned on this PC (or your Access host). Stop monitoring and the ingest goes dark. The PC stays the cloud.

    5. 5

      Phone is a second app

      The Android app is not a webcam for this PC. Same Access login, phone camera, on-device faces and COCO objects. Sideload from Cloud Settings — not this site. Windows can still ingest a phone camera over Wi‑Fi as one of its lenses.

    Avistra Access

    Four fields. One issuer. No self-signup.

    Avistra Access is a separate app on the Developer’s machine. The Windows Setup.exe is Avistra Cloud only — Access is not inside it. The Developer issues a nickname, password, and license, then sends you an Access URL. Keep Access open on the owner’s PC so Kick and activity work.

    Field 01

    Access URL

    Paste the public HTTPS address from Avistra Access (https://….trycloudflare.com). That public URL works from anywhere — same Wi‑Fi is not required. A LAN URL is same-Wi‑Fi only.

    Field 02

    Nickname

    First sign-in with a valid license lets you pick nickname and password in Cloud. There is no self-signup without a license.

    Field 03

    Password

    The password that goes with that nickname. Wrong password, no session.

    Field 04

    License

    A key the Developer issued (looks like AVESTRA-…). Must be valid and unexpired. Expired licenses cannot sign in. Installing the exe does not mint one.

    On this PC

    The computer is the cloud.

    Footage stays here

    Video, embeddings, the people database, the journal — on the machine that runs Avistra Cloud. There is no Avistra-hosted video pipe. Exceptions: optional household people sync, opt-in Cloudflare R2 backup you turn on yourself, and this marketing site.

    Camera off when idle

    Not monitoring means ingest is off. Live, occupancy, and recording only run after Start monitoring. Stop, and the selected lens goes dark.

    Estimates are estimates

    Age and height, when shown, are camera guesses with confidence — not papers, not facts. Treat them as hints. Never as identity.

    You name who it names

    Recognition only speaks names you enrolled. Triggers only do what you configure. Optional models stay dark until you turn them on. Nationality and ethnicity are not inferred by default.

    You are responsible for using the software in line with local law, workplace policy, and consent requirements for camera and biometric monitoring.

    FAQ

    Straight answers. No SaaS fog.

    Does installing create an account?

    No. Setup.exe puts Avistra Cloud on the PC. Sign-in still needs Access URL, nickname, password, and a valid unexpired license from the Developer. There is no self-signup.

    How do I get a license?

    Ask with the form on this page. It queues a request in Avistra Access. After the Developer approves, you get email with Access URL and license key. You pick nickname and password in Cloud. The form does not generate a key by itself. Expired licenses cannot sign in.

    Do I need to be on the same Wi‑Fi?

    Not if you use the public Access URL (trycloudflare, or a named host from Access). A LAN address is same-Wi‑Fi only. Testers in another country cannot use a 192.168… URL.

    Does the phone app connect to my PC?

    No. Android is a standalone second client: phone camera, on-device faces and COCO objects, its own people list and journal for that license. It does not plug into Windows Cloud as a webcam. Windows Cloud can still ingest a phone camera over Wi‑Fi as one of its sources — that feed is analysed on the PC. Access still must be reachable for login.

    Where is the Android APK?

    Not on this site. On Windows Avistra Cloud: Settings → Create Android app, then Start phone access and open /install on the phone.

    What does Live show on people and objects?

    People: Person N, or Person N · Name once enrolled. Clothing can appear in the description (for example Person 1 · Alex, dark hoodie). Objects: COCO classes only — chair, laptop, phone, bed, and so on. Not brands, not made-up furniture names.

    What cameras can Windows Cloud use?

    This PC’s USB camera, CCTVs, PTZ, and other Wi‑Fi / IP cameras over RTSP or HTTP, GoPro over USB, Wi‑Fi, or RTMP into this PC, and a phone camera over Wi‑Fi. You add named slots and switch among them. Live is analysed on the PC that runs Avistra Cloud (or your Access host) — faces, COCO objects, journal. Not a public SaaS webcam. The Android app is separate and uses the phone camera on the phone.

    Is the camera always on?

    No. When you are not monitoring, ingest is off. Start monitoring to open the selected camera. Stop monitoring to shut it.

    Where does my data go?

    On the PC that runs the app, by default. It leaves that machine only for optional household people sync, opt-in Cloudflare R2 backup you turn on, or this public marketing site (which does not host your footage).

    How do I uninstall?

    There is no second huge uninstall download. On that PC: Windows Settings → Apps → Avistra Cloud → Uninstall. Or Start Menu → Avistra Cloud → Uninstall Avistra Cloud. Or run %LOCALAPPDATA%\Programs\Avistra Cloud\Uninstall.exe. Program files go away. People and logs stay unless you check “Also remove local data.”

    Windows says the app is unrecognized.

    SmartScreen may warn on unsigned indie software. Choose More info → Run anyway only if you trust this official download from GitHub Releases linked on this site.
