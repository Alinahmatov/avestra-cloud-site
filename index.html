Capabilities

Built as a real monitor, not a demo.

Live capture, recognition, trigger evaluation, evidence, and email alerts are wired as separate services on the desktop. If one piece fails, monitoring keeps running.

Live video

Watch the camera with a visible monitoring indicator. Bounding boxes stay on the people in frame so you can see what the system is actually tracking.

People recognition

Enroll faces on the PC. Known people are named; everyone else stays Unknown. Optional voice recognition is independent of face.

Everyday actions

Detect raised hands, waves, sitting, standing, pointing, possible falls, entering or leaving an area, and other everyday poses — then decide which ones matter.

Object names

Label everyday objects in the scene — chair, laptop, phone, bed, and more — so triggers can react to what is actually in the room.

Triggers

Combine a person, an action, a zone, and a cooldown. When it fires, capture an image or clip, write a log, and optionally send an email alert.

Phone access

Open live video and alerts from your phone while the desktop app is running. Android can install the companion app from the PC; iPhone can add the site to the home screen.

How it works

Set up once. Monitor on this computer.

  1. 1

    Install on Windows

    Unzip the app and run it on the PC that has the camera. Nothing is uploaded to set up monitoring.

  2. 2

    Enroll people

    Add photos for the people you want recognized. Anyone not enrolled remains Unknown.

  3. 3

    Write triggers

    Choose an action, who it applies to, and what to do: capture, log, email alert.

  4. 4

    Start monitoring

    Hit Start on the Live view. Watch from the desktop or the phone app while this PC stays on.

Privacy-forward

The computer is the cloud.

Data stays on the PC

Video, embeddings, and event history live on the machine that runs Avestra Cloud. There is no Avestra-hosted video pipeline to send your camera to.

Estimates are estimates

Age and height, when shown, are camera estimates with confidence — not identity documents and not verified facts. Treat them as hints, never as ground truth.

You choose what fires

Recognition only names people you enroll. Triggers only do what you configure. Optional models stay off until you turn them on.

You are responsible for using the software in line with local law, workplace policy, and consent requirements for camera and biometric monitoring.
