What it sees

A room, a database, a journal.

Local AI on Windows. It recognizes faces you enrolled, names COCO objects, writes what people did, counts who is in frame, and will not sign in without a license from Alin.

Face recognition

Enroll faces on this PC. Known people show as Person N · Name. Everyone else stays Person N until you put them in the database. You don’t type labels on every frame.

COCO object detection

Chair. Laptop. Phone. Bed. Bottle. Everyday objects get names from COCO so the room is readable — and triggers can fire on what is actually there. Not a shopping catalog.

Action journal

Who entered. Who left. Wave, sit, stand, possible fall. Lines use Person N · Name, with clothing in the description when the torso read is good. Searchable, not a vibe.

People database

Its own local store on this PC. Enrolled faces, unnamed Person N tracks, history. The database lives next to the app, not in a vendor account you don’t control.

Occupancy

How many people are in frame right now while monitoring. Peak and unique counts for the day on People. Watch your space without guessing from a silent thumbnail.

FAQ

Straight answers. No SaaS fog.

Does installing create an account?

No. Setup.exe puts Avestra Cloud on the PC. Sign-in still needs Access URL, nickname, password, and a valid unexpired license from Alin. There is no self-signup.

How do I get a license?

Ask Alin with the form on this page. The form emails the request. It does not generate a key and does not mail one automatically. Expired licenses cannot sign in — ask Alin if yours lapsed.

Do I need to be on the same Wi‑Fi?

Not if you use the public Access URL (trycloudflare, or a named host from Access). A LAN address is same-Wi‑Fi only. Testers in another country cannot use a 192.168… URL.

Does the phone app connect to my PC?

No. Android is a standalone second client: phone camera, on-device faces and COCO objects, its own people list and journal for that license. Windows Cloud does not need to stay running after you sign in. Access still must be reachable for login.

Where is the Android APK?

Not on this site. On Windows Avestra Cloud: Settings → Create Android app, then Start phone access and open /install on the phone.

What does Live show on people and objects?

People: Person N, or Person N · Name once enrolled. Clothing can appear in the description (for example Person 1 · Alex, dark hoodie). Objects: COCO classes only — chair, laptop, phone, bed, and so on. Not brands, not made-up furniture names.

Is the camera always on?

No. When you are not monitoring, the camera is off. Start monitoring to open it. Stop monitoring to shut it.

Where does my data go?

On the PC that runs the app, by default. It leaves that machine only for optional household people sync, opt-in Cloudflare R2 backup you turn on, or this public marketing site (which does not host your footage).

How do I uninstall?

There is no second huge uninstall download. On that PC: Windows Settings → Apps → Avestra Cloud → Uninstall. Or Start Menu → Avestra Cloud → Uninstall Avestra Cloud. Or run %LOCALAPPDATA%\Programs\Avestra Cloud\Uninstall.exe. Program files go away. People and logs stay unless you check “Also remove local data.”

Windows says the app is unrecognized.

SmartScreen may warn on unsigned indie software. Choose More info → Run anyway only if you trust this official download from GitHub Releases linked on this site.

Uninstall

There is no separate uninstall download. After Avestra Cloud is installed, remove it on that PC:

  • Windows Settings → Apps → Avestra Cloud → Uninstall
  • Start Menu → Avestra Cloud → Uninstall Avestra Cloud
  • Or run Uninstall.exe at %LOCALAPPDATA%\Programs\Avestra Cloud\Uninstall.exe

Program files are removed. People, logs, and other local data stay unless you check “Also remove local data” in the uninstaller.
